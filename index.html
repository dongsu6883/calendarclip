Calendar Clip은 어떤 앱인가요?

Calendar Clip은 Windows PC용 무료 앱입니다. 메일·메신저 등에서 일정이 적힌 문장(예: "다음주 화요일 3시 회의")을 선택하거나 복사한 뒤 Ctrl + Alt + Space를 누르면, 앱이 문맥을 읽어 일정 제목과 날짜·시간을 자동으로 인식합니다. 사용자는 내용을 확인하고 [등록] 버튼만 누르면 본인의 Google 캘린더에 일정이 추가됩니다.

주요 기능

  • Ctrl + Alt + Space 단축키로 어디서든 바로 실행
  • 문장의 문맥을 읽어 일정 제목, 날짜, 시간을 자동 인식
  • [등록] 버튼 한 번으로 Google 캘린더에 일정 추가 (등록 전 수정 가능)
  • 월간 보기로 일정 확인, 중복·겹치는 일정 알림
  • 본인이 소유한 캘린더의 일정 수정

사용 방법

  1. 설치 파일을 내려받아 설치하고 실행합니다.
  2. [Google 계정 연결]을 눌러 본인 Google 계정으로 로그인하고 권한을 허용합니다. (처음 한 번만)
  3. 일정이 적힌 문장을 선택하거나 복사합니다.
  4. Ctrl + Alt + Space를 누르면 인식된 일정 제목과 날짜·시간이 표시됩니다.
  5. 내용을 확인하고 [등록]을 누르면 Google 캘린더에 일정이 추가됩니다.

Google 캘린더 데이터를 사용하는 방식

Calendar Clip은 Google 권한 https://www.googleapis.com/auth/calendar.events.owned 하나만 요청합니다. 이 권한은 사용자가 소유한 캘린더의 일정에만 접근하며, 다른 사람이 공유한 캘린더나 연락처·메일 등에는 접근하지 않습니다.

  • 사용 목적: 사용자가 선택한 문장으로 일정을 등록하고, 등록한 일정을 확인·수정하기 위해서입니다.
  • 사용 시점: 사용자가 [등록] 또는 수정 버튼을 눌렀을 때와 월간 보기를 열었을 때만 Google 캘린더와 직접 통신합니다. 일정은 삭제하지 않습니다.
  • 저장 위치: 데이터는 개발자 서버로 전송되거나 저장되지 않습니다. 로그인 토큰은 Windows 데이터 보호(DPAPI)로 암호화해 사용자 PC에 저장합니다.
  • Google에서 받은 데이터를 광고, 판매, 제3자 제공에 사용하지 않습니다.
  • Calendar Clip은 이미지를 생성하거나 편집하지 않으며, Google 사용자 데이터를 AI 이미지 생성이나 AI 모델 학습에 사용하지 않습니다.

광고 안내

앱 화면 하단에 쿠팡 파트너스 광고 배너가 표시됩니다. 광고 제공자는 쿠키를 사용할 수 있습니다. 이 배너에는 Google 캘린더 데이터가 전달되지 않습니다.

About Calendar Clip (English)

Calendar Clip is a free Windows desktop app. The user selects or copies a sentence such as "Meeting next Tuesday at 3 PM" and presses Ctrl + Alt + Space. The app reads the context, detects the event title, date and time, and after the user reviews it and clicks [Add], adds the event to the user's own Google Calendar.

Google user data: The app requests only one scope, https://www.googleapis.com/auth/calendar.events.owned, used solely to read, create and update events on calendars the user owns. It communicates directly with Google Calendar only when the user acts. No calendar data is sent to or stored on the developer's servers. The sign-in token is encrypted with Windows DPAPI on the user's PC. Google user data is never sold, used for advertising, or shared with third parties.

Calendar Clip does not generate or edit images, and does not use Google user data for AI image generation or AI model training.

Advertising: A Coupang Partners banner is shown at the bottom of the app. The banner does not receive any Google user data.
