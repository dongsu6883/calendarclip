Calendar Clip 개인정보처리방침

시행일: 2026-11-26 · 최종 수정: 2026-11-26

Calendar Clip은 사용자가 선택하거나 복사한 일정 문장을 내 PC에서 분석해 사용자의 Google 캘린더에 등록하는 Windows 프로그램입니다. Google 계정 정보와 캘린더 내용은 사용자 PC와 Google 사이에서만 오가며, 운영자의 서버로 보내지지 않습니다. Google 사용자 데이터는 광고에 사용하거나 다른 사람에게 판매·제공하지 않습니다.

1. 처리하는 정보와 목적

정보목적저장 위치
사용자가 복사하거나 입력한 일정 문장날짜·시간·제목을 추출해 일정 초안 작성PC 메모리에서만 처리. '나중에 등록'을 누른 경우에만 사용자 PC에 저장
Google 캘린더 일정 (제목, 시작·종료 시각, 색상, 참석자 유무, 바쁨/한가함 표시, Calendar Clip이 붙인 분류 값)월간 보기 표시, 중복·겹치는 일정 확인, 일정 등록·변경Google 서버. 프로그램 실행 중 PC 메모리에서만 사용
Google 로그인 토큰매번 다시 로그인하지 않고 캘린더에 연결사용자 PC (Windows 계정 단위로 암호화)
앱 설정 (분류 목록 등)사용자 환경 유지사용자 PC

Calendar Clip은 클립보드를 상시 감시하지 않습니다. 사용자가 단축키(Ctrl + Alt + Space)를 누르거나 직접 붙여 넣을 때만 클립보드 텍스트를 읽습니다. 회원가입이 없으며, 이름·전화번호·이메일 주소 등을 따로 수집하지 않습니다.

2. Google 사용자 데이터의 접근과 사용

Calendar Clip은 Google 계정 연결 시 다음 한 가지 권한만 요청합니다.

https://www.googleapis.com/auth/calendar.events.owned — 사용자가 소유한 캘린더의 일정 보기, 만들기, 변경

이 권한은 사용자의 기본 캘린더에서 다음 작업에만 사용합니다.

  • 사용자가 'Google에 등록'을 눌렀을 때 새 일정 만들기
  • 사용자가 '일정 변경'을 선택했을 때 기존 일정의 시간·제목·분류 바꾸기
  • 월간 보기와 중복·겹침 확인을 위해 해당 기간의 일정 읽기

Calendar Clip은 일정을 삭제하지 않으며, 사용자가 확인하지 않은 일정을 자동으로 등록하거나 변경하지 않습니다. 참석자가 있는 일정을 변경하면 Google 캘린더가 참석자에게 변경 알림을 보낼 수 있습니다.

Calendar Clip의 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

  • Google 사용자 데이터는 위에 적은 사용자용 기능에만 사용합니다.
  • Google 사용자 데이터를 운영자 서버나 제3자에게 전송, 판매, 제공하지 않습니다.
  • Google 사용자 데이터를 광고(맞춤형 광고, 리타기팅 포함)에 사용하지 않습니다.
  • 운영자를 포함한 어떤 사람도 사용자의 캘린더 내용을 열람하지 않습니다.
  • Google 사용자 데이터를 AI·머신러닝 모델 학습이나 AI 이미지 생성에 사용하지 않습니다.

3. 광고

Calendar Clip 창 하단에는 쿠팡 파트너스 광고 배너가 표시되며, 이 배너를 통한 구매 시 운영자가 일정액의 수수료를 받을 수 있습니다. 배너는 쿠팡(ads-partners.coupang.com)의 웹 콘텐츠로 불러오며, 쿠팡은 자체 정책에 따라 쿠키·기기 정보·클릭 정보를 처리할 수 있습니다. 광고에는 사용자의 일정 문장, 캘린더 내용, Google 계정 정보가 전달되지 않습니다.

4. 보관 기간과 삭제

  • 프로그램의 연결 해제 기능을 사용하면 PC에 저장된 로그인 토큰과 Google 대기 목록이 즉시 삭제됩니다.
  • Google 계정 쪽 권한은 Google 계정 > 타사 앱 및 서비스(myaccount.google.com/permissions)에서 언제든 철회할 수 있습니다.
  • 프로그램을 삭제한 뒤 %LOCALAPPDATA%\CalendarClip 폴더를 지우면 PC에 남은 모든 데이터가 삭제됩니다.
  • Calendar Clip으로 등록한 일정은 사용자의 Google 캘린더에 남으며, Google 캘린더에서 직접 관리할 수 있습니다.

5. 제3자 제공 및 처리 위탁

운영자는 사용자의 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 일정 데이터는 사용자의 PC와 Google LLC 사이에서 직접 전송되며, Google의 처리는 Google 개인정보처리방침을 따릅니다.

6. 안전성 확보 조치

  • Google과의 통신은 모두 HTTPS로 암호화됩니다.
  • 로그인은 Google 공식 로그인 화면에서 진행되며, 프로그램은 비밀번호를 받지 않습니다 (OAuth 2.0 + PKCE).
  • 로그인 토큰은 Windows 데이터 보호(DPAPI)로 암호화해 현재 Windows 사용자만 읽을 수 있게 저장합니다.

7. 이용자의 권리

이용자는 언제든 연결 해제, Google 권한 철회, 로컬 데이터 삭제를 통해 개인정보 처리를 중단할 수 있습니다. 운영자는 이용자의 데이터를 보관하지 않으므로, 열람·정정·삭제는 위 방법과 Google 캘린더에서 직접 할 수 있습니다.

Calendar Clip Privacy Policy

Effective: 2026-11-26

Calendar Clip is a Windows desktop app that reads a schedule sentence the user selects or copies, parses it on the user's PC, and adds or updates the event in the user's own Google Calendar. Calendar Clip has no server: Google account data and calendar data travel only between the user's PC and Google.

Data accessed and why

  • Scope requested: https://www.googleapis.com/auth/calendar.events.owned only.
  • Calendar events (title, start/end, color, whether guests exist, free/busy, and a private category tag set by Calendar Clip) in the user's primary calendar are read to show the month view and to detect duplicate or overlapping events.
  • Events are created or updated only after the user reviews the parsed result and clicks the save button. Calendar Clip never deletes events.
  • Clipboard text is read only when the user presses the hotkey or pastes manually, and is parsed locally.
  • The OAuth refresh token is stored on the user's PC, encrypted with Windows DPAPI.

Limited Use

Calendar Clip's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the user-facing features described above. It is never sent to the developer or any third party, never sold, never used for advertising (including retargeting or personalized ads), never read by humans, and never used to train AI or machine learning models or to generate AI images.

Advertising

The app window shows a Coupang Partners affiliate banner loaded from ads-partners.coupang.com. Coupang may use cookies and device or click information under its own policy. No Google user data, calendar content, or clipboard text is passed to the banner or to Coupang.

Retention and deletion

Using "Disconnect" in the app deletes the stored token and pending Google drafts from the PC immediately. Users can revoke access at any time at myaccount.google.com/permissions, and can delete all local data by removing the %LOCALAPPDATA%\CalendarClip folder. Events created in Google Calendar remain in the user's calendar under the user's control.

Sharing

We do not share, sell, or transfer personal data to anyone.
